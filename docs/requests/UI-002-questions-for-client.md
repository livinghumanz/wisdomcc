# Admin portal — a few things we need from you

We have built the admin portal from your handwritten notes: student records with photos,
marks entry, the growth card chart, the attendance register and the fee sheet.

A few details weren't specified in the notes. We've used sensible defaults so nothing is
held up, but we'd rather use your real answers than our guesses. None of these are difficult
to change later — they're all settings, not rebuilds.

---

## 1. What does "WCC A" mean?

Your notes list three branches: **WCC R**, **WCC G** and **WCC A**.

We've assumed R is Redhills and G is Gandhi Nagar, but we don't know what **A** is. For now
the dropdown shows your codes exactly as you wrote them.

**Please tell us the full name of each of the three branches.**

Related: the branch list you sent us earlier for the website named **Gandhi Nagar** and
**Kamaraj Nagar**. Those don't obviously match R / G / A — could you confirm which branches
are currently running, and what each should be called?

## 2. What goes in the "Category" dropdown?

Your notes show a **Category** box next to Class, but not what the options should be.

We've temporarily put in: Regular Tuition, NEET, Value-Added Course, Day Care, Spoken English.

**Please send us the list you actually want** — or tell us what Category is meant to capture.

## 3. Marks: "Out of" and "Out of 100"

Your notes show both a **Mark**, an **Out of**, and an **Out of 100** column.

We've assumed **Out of 100 is calculated automatically** — so if a student scores 45 out of 50,
the system shows 90. Staff only type the mark and the maximum.

**Is that right, or do you want to type the "out of 100" figure separately?**

## 4. Pass or Fail — who decides?

We've set it to calculate automatically: **35% or above is a pass**, and the P/F column fills
itself in.

**Is 35% the right threshold?** Should it differ by subject or by class? Or would you rather
staff tick pass/fail by hand?

## 5. The fee sheet has two "Balance" columns

Your notes show Balance twice. We've read them as:

- **Balance (fee)** = Fee Amount − Paid Amount
- **Balance (admission)** = Admission Amount − Admission Paid

We also added an **Admission Paid** box, because without it the second balance could never
change.

**Is that what you intended?** If the second Balance was meant to be a running total instead,
tell us and we'll switch it.

## 6. Jersey and Material amounts

Are these **fixed amounts** for everyone, set once per year, or does staff type a different

## 7. Internal and External marks

Are these **two separate exams** for the same subject (so a student has both an internal and an
external mark), or one record that is marked as being of one type?

We've built it as two separate records, so a subject can carry both.

## 8. Student ID

Your notes use **SID**. We're using the student's registration number for this.

**Is SID the same as the registration number, or a separate number you issue?**

## 9. Attendance — students nobody marks

If a staff member saves the register but leaves a student unmarked, we currently **record
nothing** for that student, and show a "Not marked" count so the gap is visible. We didn't want
to guess that someone was present.

There's a "Mark all present" button to make the normal day one click.

**Is that right, or should an unmarked student count as present?**

## Two things worth knowing

**Student passwords are readable.** Staff can see a student's password on screen so they can
read it back to them, which is what you asked for. The trade-off is that anyone with access to
the system or its backups can see every student's password. If any student reuses that password
elsewhere, it's exposed. We can change this later if you'd prefer.

**Photos and timetables.** Uploaded photos and timetables were never actually reaching the
website — we've fixed that as part of this work, so photo upload now works properly.
